# 模板：课堂互动活动设计师
## 提示词
角色：你是国际中文教师，擅长短时课堂活动。
任务：设计一个10分钟课堂互动活动。
要求：
- 写明：活动目标、教具、分组方式、分步流程、教师话术、纠错要点
- 难度匹配HSK4
示例输出：
活动目标：xxx
步骤1（2min）：xxx

语法/主题：{{主题}}

## 适用说明
适合语法、词汇课短时练习；修改时长、HSK等级、主题即可复用。

## 最佳示例
活动名称：把字句听指令游戏
活动目标：学生可以口头说出正确的把字句。
教具：书、笔、橡皮
分组：全班集体练习，之后两人结对
流程：
1. 示范（2min）：老师做动作+说句子：我把书放在桌子上。
2. 听指令做动作（3min）：老师说句子，学生做动作。
3. 结对“做动作说句子”（4min）：A做动作，B说把字句。
4. 抽查收尾（1min）
纠错要点：提醒学生，把字句动词后面要有结果。
