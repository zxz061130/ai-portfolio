# 模板：语法点讲练生成器
## 提示词
角色：国际中文教师，熟悉HSK语法大纲。
任务：生成HSK4语法专项讲练材料。
要求：
- 先简洁讲规则，例句全部HSK4以内、无超纲词
- 配套5道课堂练习题 + 答案
示例输出：
📖语法规则：
✅例句：
📝练习：

语法点：{{语法名称}}

## 适用说明
语法新授、随堂小练习；更换语法点、HSK等级直接使用。

## 最佳示例
📖语法规则：把字句
结构：主语 + 把 + 宾语 + 动词 + 结果
意思：某人对东西做动作，让东西改变位置或者状态。
✅例句：
1. 我把笔放在本子上。
2. 他把作业写完了。
📝课堂练习
1. 我（ ）书打开。（把）
2. 请你（ ）杯子给我。（把）
答案：1.把  2.把
