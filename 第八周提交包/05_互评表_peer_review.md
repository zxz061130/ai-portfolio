## 四、第 9 周预习：我希望助手拥有的两个工具

第 9 周是「工具调用」：让助手不只回话，还能**查表、算分、执行动作**。
我按「最想让助手替我干的两件确定性的事」来选 —— 两条都必须是**资料里能查到、机器能算准**的，
否则不如让模型直接说。

### 工具 1：`grade_lookup(指标, 级别)` —— 等级量化指标查询

| 项 | 说明 |
|---|---|
| 用途 | 回答「HSK 几级要多少词/字/语法点」这类**必须精确**的问题，避免模型背错数字 |
| 输入 | `指标 ∈ {音节, 汉字, 词汇, 语法点}`、`级别 ∈ {一级…六级, 七—九级}`、`口径 ∈ {新增, 累计}` |
| 输出 | `{值: int, 出处: "《等级标准节选.txt》第N段", 行原文: "中等 四级 116/724 300/1200 1000/3245 76/286"}` |
| 为什么值得工具化 | 现在的 RAG 靠模型「看懂表格」；0.5b 会直接说「未提及」，云端偶尔也会把「新增」当「累计」。查询是确定性的，不该交给概率 |
| 调用示例 | `grade_lookup("词汇", "四级", "累计") → 3245`；`grade_lookup("汉字", "四级", "新增") → 300` |

### 工具 2：`vocab_pick(等级, 词性, 数量)` —— 生词表筛选与出题

| 项 | 说明 |
|---|---|
| 用途 | 备课时「按 HSK 等级挑词 + 直接出练习」，替代人工翻 CSV |
| 输入 | `等级 ∈ {3,4,5,6}`、`词性 ∈ {名词,动词,介词,成语,…}`（可空）、`数量 ≤ 20`、`题型 ∈ {造句, 填空, 释义}` |
| 输出 | `{词条: [{词汇, 等级, 词性, 释义}], 题目: [...], 答案: [...], 出处: "《生词表.csv》第N行"}` |
| 为什么值得工具化 | 词汇范围必须严格落在 `data/生词表.csv` 内（超纲词会毁掉一整节课）；数量与等级筛选是纯过滤，模型很容易多给/少给 |
| 调用示例 | `vocab_pick(4, "成语", 5, "填空") → 返回 5 条 HSK4 成语 + 5 道填空题 + 答案` |

**两个工具的共性**：输入是一个闭集（枚举 + 数值上限），输出带出处字段，
失败时返回「查无此项」而不是编一个 —— 这样助手调用它们时，幻觉空间被压到最小。
